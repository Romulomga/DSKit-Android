# DSKit Android

Design system em Jetpack Compose sobre o Material 3, a base visual dos apps Android do dono. Ver o `README.md` e o
`CONVENTIONS.md`.

**Gêmeo por conceito:** `~/DSKit` (iOS, `github.com/Romulomga/DSKit`). Mesmo nome e mesma regra quando o problema existe
nas duas plataformas; o que é de uma só é dito. A base não visual é o CoreKit-Android (`~/CoreKit-Android`): o que não
desenha vai para lá, nunca para cá.

Os apps usam o DSKit Android como submódulo numa tag: mudança é release com tag aqui, nunca uma cópia local no app.
